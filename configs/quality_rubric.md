# Quality Rubric

## A. Fidelity (0-5)
- 是否忠于原文
- 是否存在编造

## B. Technical Depth (0-5)
- 是否讲清 pipeline / module / training / inference
- 是否把 pipeline 按步骤拆开并解释关键术语

## C. Experimental Rigor (0-5)
- 是否包含关键 benchmark / metric / results / ablation

## D. Comparison Quality (0-5)
- 是否比较得具体且不过度延展

## E. Writing Quality (0-5)
- 是否自然、清晰、严谨、无空话
- 是否避免机械重复标签、可读性是否良好
